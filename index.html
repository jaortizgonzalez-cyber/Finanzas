Cómo usar este panel

Actualizar un dato

Toque cualquier número o texto y escriba encima. Se guarda solo — no hay botón de guardar. El cambio aparece de inmediato en cualquier otro celular o computador donde tenga el panel abierto.

Agregar algo nuevo

Use los botones + Agregar... al final de cada sección (posición, cuenta, deuda, activo, gasto). Crea una fila nueva en blanco lista para editar.

Borrar algo

Toque la × junto al elemento. Es inmediato y no se puede deshacer.

Piso y objetivo de una posición

Son solo referencia visual — el panel le avisa con un color si el precio actual ya los tocó, pero no vende nada automáticamente. Usted sigue vendiendo desde Trii.

Cuando llegue la declaración de renta

Copie ahí el patrimonio bruto, patrimonio líquido, y cualquier activo (vivienda, vehículo) a su valor comercial real en la sección "Activos fijos" y "Declaración de renta". El patrimonio neto de arriba se recalcula solo.

Primera vez conectando Firebase

  1. Vaya a console.firebase.google.com → cree un proyecto
  2. Build → Realtime Database → crear, modo bloqueado
  3. En la pestaña Reglas, pegue:
    {"rules":{".read":"auth != null",".write":"auth != null"}}
  4. Build → Authentication → Sign-in method → habilite Anonymous
  5. ⚙ Configuración del proyecto → Sus apps → cree una app web → copie el firebaseConfig
  6. Abra este archivo HTML con un editor de texto, busque FIREBASE_CONFIG cerca del final, y reemplace los valores "PEGUE_AQUI..." por los suyos
  7. Guarde el archivo y ábralo en el navegador — debería decir "sincronizado" arriba a la derecha

Para usarlo desde el celular también

Suba este mismo archivo a GitHub Pages (igual que su arcada de juegos) y ábralo desde ahí en vez de como archivo local — evita restricciones de algunos navegadores con Firebase.
